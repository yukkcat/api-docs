模型和渠道说明请查看[模型介绍](/docs/models/overview)。本页只介绍接口、参数和请求示例。

把 `base_url` 换成 `https://api.klong.lat/v1`，官方 SDK 直接用。

> 大部分程序填写 `https://api.klong.lat` 即可。

```http
POST https://api.klong.lat/v1/images/generations   # 文生图 (application/json)
POST https://api.klong.lat/v1/images/edits         # 图像编辑 (multipart/form-data)
Authorization: Bearer <API_KEY>
```

## 参数

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `model` | 是 | 模型名称；分组和渠道能力见[模型介绍](/docs/models/overview) |
| `prompt` | 是 | 提示词，中英文皆可 |
| `size` | 否 | `宽x高` 像素，如 `1024x1024`、`3840x2160`；两个 `-exact` 模型会严格按该尺寸输出 |
| `quality` | 否 | VIP 固定为 `medium`；High 支持 `medium` / `high`；官方渠道支持 `low` / `medium` / `high` / `xhigh` / `max` |
| `n` | 否 | 一次出几张，默认 `1` |
| `response_format` | 否 | `url`（默认）或 `b64_json` |
| `stream` | 否 | `true` 时通过当前 SSE 连接持续返回进度 |
| `image` | 编辑必填 | 仅 `/edits`：参考图文件，可重复传入多张 |

package main

import (

    req.Header.Set("Content-Type", "application/json")

    if err != nil { panic(err) }
    defer resp.Body.Close()

    data, _ := io.ReadAll(resp.Body)
    fmt.Println(string(data))
}

### 精确尺寸请求

需要图片严格符合指定像素尺寸时，在 `/generations` 中使用 `gpt-image-2-exact` 或 `gpt-image-2.5-exact`，并传入 `size`。模型处理规则见[模型介绍](/docs/models/overview)。

```bash
curl https://api.klong.lat/v1/images/generations \
  -H "Authorization: Bearer <API_KEY>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2-exact",
    "prompt": "未来城市夜景，霓虹灯光，电影感广角构图",
    "size": "3840x2160"
  }'
```

返回图片的最终尺寸会严格为 `3840x2160`。显式像素尺寸的宽、高需在 `64`～`4096` 之间，总像素不得超过 `4096x4096`；宽高比差异较大时，画面可能被裁切或拉伸。

### 指定质量档位

`quality` 的可用值取决于当前渠道，完整对照见[模型介绍](/docs/models/overview)。下面示例展示官方渠道请求；切换另一个官方模型时只需替换 `model`。

例如，使用官方渠道模型并指定 4K 和质量档：

```bash
curl https://api.klong.lat/v1/images/generations \
  -H "Authorization: Bearer <API_KEY>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2.5-sunburst",
    "prompt": "高端香水产品海报，黑色背景，轮廓光，商业摄影",
    "size": "3840x2160",
    "quality": "xhigh"
  }'
```

具体可用参数以 API 控制台和上游服务为准。

### 一次出多张 · `n`

```bash
curl https://api.klong.lat/v1/images/generations \
  -H "Authorization: Bearer <API_KEY>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "湖蓝色调的山谷，清晨薄雾，极简插画风",
    "size": "1024x1024",
    "n": 2
  }'
```

返回的 `data` 数组中就是对应数量的图片。SDK 中同样传 `n=2`，`n` 在 `/edits` 上也生效。

### 图像编辑 · cURL

```bash
curl https://api.klong.lat/v1/images/edits \
  -H "Authorization: Bearer <API_KEY>" \
  -F "model=gpt-image-2" \
  -F "image=@otter.png" \
  -F "prompt=给这只海獭戴上一顶贝雷帽"
```

编辑时不传 `size`，沿用参考图尺寸。不要手动填写 multipart 的 boundary。

### 多张参考图 · cURL

同一个字段名重复出现即可，顺序保留，提示词里用“第一张 / 第二张”指代：

```bash
curl https://api.klong.lat/v1/images/edits \
  -H "Authorization: Bearer <API_KEY>" \
  -F "model=gpt-image-2" \
  -F "image[]=@teapot.png" \
  -F "image[]=@duck.png" \
  -F "prompt=把第二张图里的黄色小鸭子放在第一张图的茶壶旁边，保持同样的桌面和光线"
```

字段名写 `image[]` 或 `image` 都可以，重复出现即为多张。官方 SDK 传数组时发送的是 `image[]`。

### 多张参考图 · Python (OpenAI SDK)

```python
resp = client.images.edit(
    model="gpt-image-2",
    image=[open("teapot.png", "rb"), open("duck.png", "rb")],
    prompt="把第二张图里的黄色小鸭子放在第一张图的茶壶旁边",
)
```

## 响应

```json
{
  "created": 1781837823,
  "data": [
    { "url": "https://<DOWNLOAD_HOST>/generated/<FILE>.png" }
  ]
}
```

不传 `response_format` 时返回 `url`；传 `response_format=b64_json` 时，每个元素改为 `{"b64_json": "..."}`。`n>1` 时，`data` 数组中按顺序返回多张图片。
