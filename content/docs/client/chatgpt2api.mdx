ChatGPT2API 是独立部署的 OpenAI 兼容项目，支持文本模型与 GPT Image 2。

## 项目地址

[在 GitHub 查看 ChatGPT2API](https://github.com/yukkcat/chatgpt2api)

```bash
git clone https://github.com/yukkcat/chatgpt2api.git
```

部署方式、环境变量和更新记录以项目 README 为准。

不需要自行部署时，直接在客户端填写：

```text
API 地址：https://api.klong.lat
```
