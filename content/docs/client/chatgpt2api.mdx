ChatGPT2API Go 把 ChatGPT 网页端能力封装成可自托管的 API 服务，提供 OpenAI / Anthropic 兼容接口、账号池、图片管理、日志审计和 Web 管理面板。

[GitHub 仓库](https://github.com/yukkcat/gpt2api-go) · [v1.4.2 Release](https://github.com/yukkcat/gpt2api-go/releases/tag/v1.4.2) · [更新日志](https://github.com/yukkcat/gpt2api-go/blob/main/CHANGELOG.md) · [README](https://github.com/yukkcat/gpt2api-go/blob/main/README.md)

> **风险提示：** 本项目通过技术研究访问 ChatGPT Web，并非 OpenAI 官方 API。上游接口和风控策略可能变化，也可能导致账号受限或封禁。请勿使用重要、常用或高价值账号，并遵守服务条款与适用法律。

## 当前实现

本文已按 `yukkcat/gpt2api-go` 的 `v1.4.2` 源码同步。后端使用 Go，前端使用 Next.js，前端静态产物由 Go 服务直接托管。

| 能力 | 当前实现 |
| --- | --- |
| 兼容接口 | Chat Completions、Responses、Anthropic Messages、图片生成与编辑 |
| 多模态 | OpenAI 风格图片输入、参考图上传、轻量文本和 PDF 提取 |
| 账号池 | 多账号选择、额度与状态、AT / RT、图片并发、失败与限流处理 |
| 工具调用 | OpenAI `tool_calls`、Anthropic `tool_use`、Responses `function_call` |
| 图片任务 | 同步响应、SSE 流式响应、PostgreSQL 持久化异步任务 |
| 管理能力 | Web 面板、图片管理、调用日志、链路追踪和运行指标 |

## 快速部署

### Docker

```bash
git clone https://github.com/yukkcat/gpt2api-go.git
cd gpt2api-go

# 编辑 config.json，将 auth-key 改为自己的强密钥
docker compose up -d --build
```

默认地址：

| 用途 | 地址 |
| --- | --- |
| 管理面板 | `http://localhost:3000` |
| API Base URL | `http://localhost:3000/v1` |

也可以直接构建并运行单个容器：

```bash
docker build -t chatgpt2api-go .
docker run --rm \
  -p 3000:80 \
  -v "$PWD/data:/app/data" \
  -e CHATGPT2API_AUTH_KEY=<设置一个强密钥> \
  chatgpt2api-go
```

## API 接口

所有 AI 接口都使用 Bearer Key：

```http
Authorization: Bearer <auth-key>
```

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/v1/models` | `GET` | 查询当前可用模型 |
| `/v1/chat/completions` | `POST` | OpenAI Chat Completions 兼容入口 |
| `/v1/responses` | `POST` | OpenAI Responses 兼容入口 |
| `/v1/messages` | `POST` | Anthropic Messages 兼容入口 |
| `/v1/images/generations` | `POST` | 图片生成；也可提交或查询异步任务 |
| `/v1/images/edits` | `POST` | 图片编辑；支持多张参考图和异步任务 |
| `/v1/images/tasks/{task_id}` | `GET` | 查询并领取当前密钥所属的异步图片任务 |
| `/v1/images/tasks/{task_id}/results/{position}` | `GET` | 下载已经领取的异步图片结果 |

### 文本示例

```bash
curl http://localhost:3000/v1/chat/completions \
  -H "Authorization: Bearer <auth-key>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5",
    "messages": [{"role":"user","content":"介绍一下这个项目"}],
    "stream": true
  }'
```

### 同步图片示例

```bash
curl http://localhost:3000/v1/images/generations \
  -H "Authorization: Bearer <auth-key>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "一只漂浮在太空里的猫，电影感光影",
    "n": 1
  }'
```

## 异步图片任务

异步能力已经在源码中实现。它不是一个新模型，也不是 `stream: true`：客户端提交原来的图片请求并加入 `async: true`，服务立即返回任务 ID，再由后台 Worker 处理。

```text
提交 async=true → 返回 202 和 task_id → 后台生成 → 轮询任务 → 领取结果
```

### 服务端启用条件

异步任务默认关闭，必须同时满足：

1. 账号池存储使用 PostgreSQL：`STORAGE_BACKEND=postgres`。
2. 设置 `DATABASE_URL` 和 `CHATGPT2API_ACCOUNT_ENCRYPTION_KEY`。
3. 设置 `CHATGPT2API_ASYNC_IMAGES_ENABLED=true`。
4. 在 `CHATGPT2API_ASYNC_IMAGE_ALLOWED_SUBJECTS` 中明确加入允许提交任务的 User Key `subject_id`；管理员根密钥对应 `admin`。
5. 多实例运行时，所有 Worker 共同挂载同一个 `CHATGPT2API_ASYNC_IMAGE_ASSET_ROOT`。

### 提交任务

```bash
curl http://localhost:3000/v1/images/generations \
  -H "Authorization: Bearer <auth-key>" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: stable-request-id" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "一只漂浮在太空里的猫",
    "async": true
  }'
```

服务返回 HTTP `202`，并通过响应体、`Location` 和 `Retry-After` 告诉客户端如何查询：

```json
{
  "id": "img_...",
  "object": "image.task",
  "status": "queued",
  "mode": "generation",
  "model": "gpt-image-2",
  "created_at": 1787190000,
  "expires_at": 1787193600,
  "poll_url": "/v1/images/tasks/img_...?model=gpt-image-2",
  "retry_after_seconds": 4
}
```

`Idempotency-Key` 可避免客户端超时重试时重复创建任务，也可以在请求体中使用同值的 `idempotency_key`。请求头和请求体同时提供时，两者必须一致。

### 查询并领取结果

```bash
curl "http://localhost:3000/v1/images/tasks/<task_id>?model=gpt-image-2" \
  -H "Authorization: Bearer <auth-key>"
```

查询必须使用**提交任务时的同一个 API Key 和同一个 `model`**。任务状态包括：

| 状态 | 含义 |
| --- | --- |
| `queued` | 已进入队列，等待 Worker |
| `running` | Worker 正在调用上游 |
| `succeeded` | 已生成，可领取结果 |
| `failed` | 任务失败，返回 OpenAI 风格错误 |

首次成功领取返回 HTTP `200` 和 `data[]`：

```json
{
  "id": "img_...",
  "object": "image.task",
  "status": "succeeded",
  "model": "gpt-image-2",
  "data": [{"url":"/v1/images/tasks/img_.../results/0?model=gpt-image-2","revised_prompt":"..."}],
  "usage": {"total_tokens": 123}
}
```

省略 `response_format` 或传入 `url` 时返回下载地址；显式传入 `b64_json` 时直接返回 Base64。

> **只有 `data[]` 成功领取一次，图片并非只能下载一次。** 再次查询同一任务会返回 `404`，避免下游重复结算；URL 可在任务过期前使用相同的 Bearer Key 重复下载。

```bash
curl -L \
  -H "Authorization: Bearer <auth-key>" \
  "http://localhost:3000/v1/images/tasks/<task_id>/results/0?model=gpt-image-2" \
  -o image.png
```

如果网关不便转发 GET，也可通过原图片接口查询。等待中会返回 HTTP `202`，成功时返回 HTTP `200`：

```bash
curl http://localhost:3000/v1/images/generations \
  -H "Authorization: Bearer <auth-key>" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-image-2","task_id":"img_..."}'
```

图片编辑同样支持异步：在 `/v1/images/edits` 的 multipart 请求中加入 `-F "async=true"`。`async: true` 与 `stream: true` 不能同时使用。

## 异步任务配置

| 环境变量 | 默认值 | 说明 |
| --- | --- | --- |
| `CHATGPT2API_ASYNC_IMAGES_ENABLED` | `false` | 是否启用异步图片任务；仅支持 PostgreSQL |
| `CHATGPT2API_ASYNC_IMAGE_ALLOWED_SUBJECTS` | 空 | 允许提交任务的 `subject_id` 白名单；空值拒绝全部 |
| `CHATGPT2API_ASYNC_IMAGE_WORKERS` | `8` | 后台 Worker 数，范围 1–64 |
| `CHATGPT2API_ASYNC_IMAGE_QUEUE_CAPACITY` | `64` | 全局未完成任务上限 |
| `CHATGPT2API_ASYNC_IMAGE_OWNER_OUTSTANDING` | `8` | 单个 User Key 未完成任务上限 |
| `CHATGPT2API_ASYNC_IMAGE_OWNER_SUBMISSIONS_PER_MINUTE` | `30` | 单个 User Key 每分钟提交上限 |
| `CHATGPT2API_ASYNC_IMAGE_RESULT_TTL_MINUTES` | `60` | 未领取结果保留时间，最长 7 天 |
| `CHATGPT2API_ASYNC_IMAGE_MAX_STORED_BYTES` | `10 GiB` | 未领取结果的全局存储上限 |
| `CHATGPT2API_ASYNC_IMAGE_ASSET_ROOT` | `data/image-jobs` | 异步输入与结果文件目录 |

## 本地开发

Go 版本以仓库 `go.mod` 为准：

```bash
go test ./...
make run
```

重新构建 Web 面板后运行：

```bash
make web
make run
```
