ChatGPT2API is a self-hosted OpenAI-compatible project with support for text models and GPT Image 2.

## Project

[View ChatGPT2API on GitHub](https://github.com/yukkcat/chatgpt2api)

```bash
git clone https://github.com/yukkcat/chatgpt2api.git
```

Refer to the project README for deployment, environment variables, and release notes.
