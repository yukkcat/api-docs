[GitHub repository](https://github.com/yukkcat/chatgpt2api)

ChatGPT2API provides text, image, and file generation, multi-account management, and a web administration console.

> This project connects to the ChatGPT website through reverse engineering and is not an official OpenAI service. Upstream changes can break the API or lead to account restrictions or bans. Do not use important accounts.

## Docker Compose

```bash
git clone https://github.com/yukkcat/chatgpt2api.git
cd chatgpt2api
cp .env.example .env
# Edit .env and set a private CHATGPT2API_AUTH_KEY
test -f config.json || printf '{}\n' > config.json
docker compose up -d
```

SQLite is used by default, so no separate database is required.

| Entry | Address |
| --- | --- |
| Administration console | `http://localhost:3000` |
| OpenAI-compatible API | `http://localhost:3000/v1` |
| Data directory | `./data` |

Do not commit your local `.env`, `config.json`, or `data/`.

## One-line installer

```bash
curl -fsSL https://raw.githubusercontent.com/yukkcat/chatgpt2api/main/deploy/install.sh | sudo bash
```

The installer supports SQLite, a local PostgreSQL container, or an existing PostgreSQL URL.

## PostgreSQL

Start PostgreSQL 18 with Compose:

```bash
docker compose -f docker-compose.yml -f docker-compose.postgres.yml up -d
```

Connect to an existing PostgreSQL database:

```dotenv
DATABASE_URL=postgresql://user:password@host:5432/database
```

## API endpoints

All AI endpoints use a Bearer key:

```http
Authorization: Bearer <auth-key>
```

| Endpoint | Method | Description |
| --- | --- | --- |
| `/v1/models` | `GET` | Model list |
| `/v1/chat/completions` | `POST` | Chat Completions |
| `/v1/responses` | `POST` | Responses API |
| `/v1/messages` | `POST` | Anthropic Messages |
| `/v1/images/generations` | `POST` | Image generation |
| `/v1/images/edits` | `POST` | Image editing |

## Key configuration

| Setting | Default | Purpose |
| --- | --- | --- |
| `CHATGPT2API_AUTH_KEY` | Required | Administrator and default API key |
| `DATABASE_URL` | SQLite | Database connection |
| `CHATGPT2API_BASE_URL` | Current service URL | Public image and file URLs |

Manage the remaining settings in the administration console. See the repository's [deployment guide](https://github.com/yukkcat/chatgpt2api/blob/main/docs/deployment.md) for upgrades, backups, and troubleshooting.
