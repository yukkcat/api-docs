import { Tabs, Tab } from 'fumadocs-ui/components/tabs';

Set `base_url` to `https://api.klong.lat/v1` to use the OpenAI SDK directly.

This page covers chat calls. For image models, see [Chat / Responses image generation](/en/docs/image/openai-chat-responses) for requests and image responses.

> For most clients, enter `https://api.klong.lat` as the API address.

```http
POST https://api.klong.lat/v1/chat/completions
Authorization: Bearer <API_KEY>
Content-Type: application/json
```

  }
}

## Streaming

Set `stream: true` to receive generated content incrementally over SSE.

<Tabs items={['cURL', 'Python', 'Node.js']}>
<Tab>

```bash
curl -N https://api.klong.lat/v1/chat/completions \
  -H "Authorization: Bearer <API_KEY>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.4-mini",
    "messages": [{ "role": "user", "content": "Write a short welcome message." }],
    "stream": true
  }'
```

</Tab>
<Tab>

```python
stream = client.chat.completions.create(
    model="gpt-5.4-mini",
    messages=[{"role": "user", "content": "Write a short welcome message."}],
    stream=True,
)

for chunk in stream:
    text = chunk.choices[0].delta.content
    if text:
        print(text, end="", flush=True)
```

const stream = await client.chat.completions.create({

## Multi-turn conversations

The endpoint does not remember earlier requests automatically. Include the previous messages again when continuing a conversation.

```json
{
  "model": "gpt-5.4-mini",
  "messages": [
    { "role": "system", "content": "You are a translation assistant." },
    { "role": "user", "content": "Translate hello into Chinese." },
    { "role": "assistant", "content": "你好。" },
    { "role": "user", "content": "What about good night?" }
  ]
}
```

## Image input

Models with vision support accept text and image URLs in the same `content` array.

```bash
curl https://api.klong.lat/v1/chat/completions \
  -H "Authorization: Bearer <API_KEY>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.4",
    "messages": [{
      "role": "user",
      "content": [
        { "type": "text", "text": "Describe this image." },
        {
          "type": "image_url",
          "image_url": { "url": "https://example.com/image.png" }
        }
      ]
    }]
  }'
```

## Common parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `model` | Yes | A model name from [Chat models](./models) |
| `messages` | Yes | Conversation messages using roles such as `system`, `user`, and `assistant` |
| `stream` | No | Set to `true` for streaming; defaults to `false` |
| `temperature` | No | Sampling randomness from `0` to `2` |
| `top_p` | No | Nucleus sampling; usually tune either this or `temperature` |
| `max_completion_tokens` | No | Maximum tokens generated for this response |
| `tools` | No | Tools the model may call |
| `tool_choice` | No | Controls whether and which tool is called |
| `response_format` | No | Requests JSON or another structured output format |

Optional parameter support varies by model. When unsure, start with only `model` and `messages`.

## Response

```json
{
  "id": "chatcmpl_xxx",
  "object": "chat.completion",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "Hello, I am an AI assistant available through the API."
      },
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 28,
    "completion_tokens": 18,
    "total_tokens": 46
  }
}
```

For non-streaming requests, read `choices[0].message.content`. For streaming requests, read `choices[0].delta.content` from each chunk.

## Common errors

| Status | What to check |
| --- | --- |
| `400` | Model name, `messages` structure, and supported parameters |
| `401` | API key and the `Bearer ` prefix |
| `429` | Available account quota or request concurrency |
| `500` / `502` | Retry later; contact support if failures continue |
