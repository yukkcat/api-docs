The Responses API is the recommended interface for new projects and supports simple text input, multimodal content, and tool calls.

For the `image_generation` tool and image result parsing, see [Chat / Responses image generation](/en/docs/image/openai-chat-responses).

```http
POST https://api.klong.lat/v1/responses
Authorization: Bearer <API_KEY>
Content-Type: application/json
```

  }
}

## Instructions and messages

Pass plain text directly as `input`, or separate high-priority behavior into `instructions`:

```json
{
  "model": "gpt-5.4-mini",
  "instructions": "You are a concise technical assistant.",
  "input": "What is SSE?"
}
```

Use an array for multiple messages:

```json
{
  "model": "gpt-5.4-mini",
  "input": [
    { "role": "developer", "content": "Answer only in English." },
    { "role": "user", "content": "Explain the Responses API." }
  ]
}
```

## Streaming

```bash
curl -N https://api.klong.lat/v1/responses \
  -H "Authorization: Bearer <API_KEY>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.4-mini",
    "input": "Write a short welcome message.",
    "stream": true
  }'
```

Streaming uses SSE. Text deltas arrive as `response.output_text.delta` events.

## Common parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `model` | Yes | A model name from [Chat models](./models) |
| `input` | Yes | A string or message array |
| `instructions` | No | High-priority instructions for this request |
| `stream` | No | Set to `true` for SSE streaming |
| `max_output_tokens` | No | Maximum generated tokens |
| `tools` | No | Tools available to the model |
| `tool_choice` | No | Controls tool selection |

## Response

Official SDKs expose the combined text as `response.output_text`. Raw HTTP responses contain an `output` array that may also include tool calls and reasoning items, so do not assume text is always the first item.
