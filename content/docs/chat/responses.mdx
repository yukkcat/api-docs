Authorization: Bearer <API_KEY>

    fmt.Println(string(data))
}

import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

public class Main {
  public static void main(String[] args) throws Exception {
    String body = """
      {"model":"gpt-5.4-mini","input":"用一句话介绍你自己。"}
      """;

    HttpRequest request = HttpRequest.newBuilder()
        .uri(URI.create("https://api.klong.lat/v1/responses"))
        .header("Authorization", "Bearer <API_KEY>")
        .header("Content-Type", "application/json")
        .POST(HttpRequest.BodyPublishers.ofString(body))
        .build();

    var response = HttpClient.newHttpClient().send(
        request, HttpResponse.BodyHandlers.ofString());
    System.out.println(response.body());
  }
}

## 指令与消息

简单文本可直接传给 `input`。需要分离系统指令时，使用 `instructions`：

```json
{
  "model": "gpt-5.4-mini",
  "instructions": "你是一个简洁的技术助手。",
  "input": "什么是 SSE？"
}
```

多条消息使用数组：

```json
{
  "model": "gpt-5.4-mini",
  "input": [
    { "role": "developer", "content": "只用中文回答。" },
    { "role": "user", "content": "介绍一下 Responses API。" }
  ]
}
```

## 流式输出

```bash
curl -N https://api.klong.lat/v1/responses \
  -H "Authorization: Bearer <API_KEY>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.4-mini",
    "input": "写一句欢迎语。",
    "stream": true
  }'
```

流式输出使用 SSE 事件，文本增量事件类型为 `response.output_text.delta`。

## 常用参数

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `model` | 是 | [对话模型](./models) 中的模型名 |
| `input` | 是 | 字符串或消息数组 |
| `instructions` | 否 | 本次请求的高优先级指令 |
| `stream` | 否 | `true` 开启 SSE 流式输出 |
| `max_output_tokens` | 否 | 最多生成的 token 数 |
| `tools` | 否 | 模型可用的工具列表 |
| `tool_choice` | 否 | 控制工具调用方式 |

## 响应

SDK 中可直接读取 `response.output_text`。HTTP 响应的完整内容位于 `output` 数组；数组也可能包含工具调用或推理项，不要假设文本永远在第一项。
