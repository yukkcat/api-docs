Claude models support both the OpenAI-compatible format and the native Anthropic Messages format.

```http
POST https://api.klong.lat/v1/messages
x-api-key: <API_KEY>
anthropic-version: 2023-06-01
Content-Type: application/json
```

import (

    if err != nil { panic(err) }
    defer resp.Body.Close()
    data, _ := io.ReadAll(resp.Body)
    fmt.Println(string(data))
}

## System instructions

Anthropic requests use a top-level `system` field instead of placing a system message in `messages`:

```json
{
  "model": "claude-sonnet-4-6",
  "system": "You are a concise technical assistant.",
  "max_tokens": 1024,
  "messages": [{ "role": "user", "content": "What is SSE?" }]
}
```

## Streaming

Add `"stream": true` to the request body. The response is returned as SSE events.

## Common parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `model` | Yes | A [Claude model](./models#claude) name |
| `messages` | Yes | An array of `user` and `assistant` messages |
| `max_tokens` | Yes | Maximum generated tokens |
| `system` | No | System instructions |
| `stream` | No | Set to `true` for SSE streaming |
| `temperature` | No | Sampling randomness |
| `tools` | No | Tools available to the model |

## Response

```json
{
  "id": "msg_xxx",
  "type": "message",
  "role": "assistant",
  "content": [{ "type": "text", "text": "Hello, I am Claude." }],
  "stop_reason": "end_turn"
}
```

Text is available at `content[0].text`.
