Claude 模型除了支持 OpenAI 兼容格式，也可以使用 Anthropic 原生 Messages 格式。

```http
POST https://api.klong.lat/v1/messages
x-api-key: <API_KEY>
anthropic-version: 2023-06-01
Content-Type: application/json
```

package main

import (
    "bytes"
    "fmt"

func main() {

    req, _ := http.NewRequest("POST", "https://api.klong.lat/v1/messages", bytes.NewReader(body))

    req.Header.Set("anthropic-version", "2023-06-01")
    req.Header.Set("Content-Type", "application/json")
    resp, err := http.DefaultClient.Do(req)
    if err != nil { panic(err) }
    defer resp.Body.Close()
    data, _ := io.ReadAll(resp.Body)
    fmt.Println(string(data))
}

import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;

public class Main {
  public static void main(String[] args) throws Exception {

  }
}

## 系统指令

Anthropic 格式的系统指令使用顶层 `system`，不放在 `messages` 中：

```json
{
  "model": "claude-sonnet-4-6",
  "system": "你是一个简洁的技术助手。",
  "max_tokens": 1024,
  "messages": [
    { "role": "user", "content": "什么是 SSE？" }
  ]
}
```

## 流式输出

在请求体中加入 `"stream": true`。流式结果使用 SSE 返回。

## 常用参数

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `model` | 是 | [Claude 模型](./models#claude) 名 |
| `messages` | 是 | `user` 与 `assistant` 消息数组 |
| `max_tokens` | 是 | 本次最多生成的 token 数 |
| `system` | 否 | 系统指令 |
| `stream` | 否 | `true` 开启 SSE 流式输出 |
| `temperature` | 否 | 采样随机性 |
| `tools` | 否 | 可用工具列表 |

## 响应

```json
{
  "id": "msg_xxx",
  "type": "message",
  "role": "assistant",
  "content": [
    { "type": "text", "text": "你好，我是 Claude。" }
  ],
  "stop_reason": "end_turn"
}
```

文本位于 `content[0].text`。
